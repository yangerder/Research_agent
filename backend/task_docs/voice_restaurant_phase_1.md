# 餐廳語音 Phase 1：情境記憶階段

## 任務目標
請閱讀以下情境卡，並盡量記住朋友限制與餐廳選項。

建議閱讀時間：**60 秒**。

## 情境卡
你正在幫朋友們安排一場週末聚餐。這場聚餐共有 6 個人，包含你自己與 5 位朋友。

| 人物 | 條件 |
|---|---|
| 你 | 希望交通方便，價格不要太高 |
| 朋友 A | 吃素 |
| 朋友 B | 不吃辣 |
| 朋友 C | 預算最多 600 元 |
| 朋友 D | 19:30 才能到 |
| 朋友 E | 希望餐廳可以坐久聊天 |

目前有以下 4 種餐廳選項：

| 餐廳類型 | 特徵 |
|---|---|
| 義大利餐廳 | 適合聊天，素食選擇較多，價格中等 |
| 火鍋店 | 選擇多，但可能比較吵，有些湯底偏辣 |
| 日式居酒屋 | 氣氛好，可以坐久，但素食選擇較少 |
| 韓式料理 | 味道重、可能很受歡迎，但通常偏辣，素食選擇較少 |

閱讀完成後，請按右下角按鈕進入語音討論階段。
